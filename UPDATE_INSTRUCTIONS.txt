ИНСТРУКЦИЯ ПО ОБНОВЛЕНИЮ / UPDATE INSTRUCTIONS
================================================

ВАМ НУЖНО ОБНОВИТЬ КОД НА ВАШЕМ КОМПЬЮТЕРЕ!
YOU NEED TO UPDATE THE CODE ON YOUR COMPUTER!

Шаги / Steps:

1. ОСТАНОВИТЕ веб-сервер (если запущен)
   STOP the web server (if running)
   - Нажмите Ctrl+C в окне где запущен run_web.bat
   - Press Ctrl+C in the window where run_web.bat is running

2. ОБНОВИТЕ код
   UPDATE the code
   - Запустите update.bat
   - Run update.bat

3. ПЕРЕЗАПУСТИТЕ веб-сервер
   RESTART the web server
   - Запустите run_web.bat
   - Run run_web.bat

4. ОБНОВИТЕ страницу в браузере
   REFRESH the page in browser
   - Нажмите Ctrl+F5 (полное обновление)
   - Press Ctrl+F5 (hard refresh)
